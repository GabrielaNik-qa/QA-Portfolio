# DOC-004: The iTasker menu is described with and without a Messages option

| Field | Details |
|-------|---------|
| **ID** | DOC-004 |
| **Type** | Requirement defect |
| **Severity / Priority** | Minor / Medium |
| **Status** | Open |
| **Requirement** | User Story 2.2.8, 2.2.17 and 2.2.17.3 |
| **Related test cases** | TC-IT-07-001, TC-IT-06-007 |
| **Reported by** | Gabriela Nikolova |

## Description
Section 2.2.17 lists three options in the iTasker menu: Profile, Preferences and Log out. Sections 2.2.8 and 2.2.17.3 describe a Messages option in the same menu.

## Expected
One definition of the menu contents.

## Impact on testing
The expected result of TC-IT-07-001 is ambiguous, and the way to reach chat is unclear.

## Suggested resolution
Add Messages to section 2.2.17, or describe another way to reach it.
