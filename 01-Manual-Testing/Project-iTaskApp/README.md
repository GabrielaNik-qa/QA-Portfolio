# iTaskApp - Manual Testing Project

## 📌 Project Overview
iTaskApp is a multi-role web platform that connects **Clients** who post tasks with **Contractors** who complete them, managed by **Admins**.

| Item | Details |
|------|---------|
| **Company** | iTaskApp Inc. (Toronto, Canada) |
| **My Role** | QA Engineer Intern |
| **Testing Type** | Manual (Functional, Integration, Regression) |
| **Roles Covered** | Client, Contractor, Admin |
| **Tools** | Jira, Confluence, Excel, Git |

## 🎯 Scope
**In scope:** registration/login, task lifecycle, role permissions, admin management, notifications
**Out of scope:** performance, security penetration, native mobile apps

## 🧪 Test Design Techniques
- Boundary Value Analysis (BVA)
- Equivalence Partitioning (EP)
- Cross-Role Permission Matrix
- Error Guessing
